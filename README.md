# FFchatgram

A private, real-time messaging application inspired by Telegram, built with React and Firebase.

## Setup Instructions

To run this project locally, you will need Node.js installed on your computer.

### 1. Initialize the Project

Create a new directory and setup a React app inside it:
npx create-react-app ffchatgram
cd ffchatgram

### 2. Install Dependencies

Install Firebase and TailwindCSS (for styling):
npm install firebase
npm install -D tailwindcss
npx tailwindcss init

### 3. Replace Files

Replace the files generated by `create-react-app` with the files provided in this repository (from the zip).

### 4. Firebase Configuration (CRITICAL STEP)

Because this app works completely independently on your own hardware, you need to connect it to your own Firebase Database.

1. Go to [Firebase Console](https://console.firebase.google.com/).
2. Click **"Add project"** and name it something like `ffchatgram-db`.
3. Go to **Build > Authentication**. Click "Get Started", go to the "Sign-in method" tab, enable **Anonymous**, and save.
4. Go to **Build > Firestore Database**. Click "Create database". Start in **Test mode** (so you can read/write data immediately).
5. Go to Project Settings (the gear icon top left). Under "Your apps", click the **Web icon (</>)** to register an app. Name it `ffchatgram-web`.
6. You will see a `firebaseConfig` block. Copy the keys (`apiKey`, `projectId`, etc.).
7. Open `src/App.js` in your code editor and replace the placeholder `firebaseConfig` object at the top of the file with your actual keys.

### 5. Run the App

npm start

The app will open in your browser at `http://localhost:3000`. You can copy the URL in the browser and send it to a friend (or open an incognito window) to test the real-time chat!
