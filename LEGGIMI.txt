CIAO!

L'app adesso è una PWA (Progressive Web App) completa e installabile su Smartphone!

Per usarla per test:
1. Fai doppio click sul file "index.html" per aprirlo nel tuo browser.
2. Per chattare online dovrai configurare le tue chiavi Firebase gratuitamente (seguendo le istruzioni a schermo).

COME FARLA INSTALLARE SU SMARTPHONE (iPhone/Android) COME APP VERA E PROPRIA:
Per permettere ai tuoi amici di avere l'app "FFchatgram" sulla schermata Home del loro telefono (con l'icona e senza le barre di Chrome/Safari), DEVI caricare questi file online in HTTPS.

Carica gratuitamente i file (index.html, manifest.json, sw.js) su una piattaforma di hosting web (come Netlify, Vercel, o GitHub Pages). 
Quando i tuoi amici apriranno il link fornito dall'hosting tramite telefono, il browser gli chiederà "Vuoi installare l'app?".
