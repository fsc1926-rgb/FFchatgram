Database Richiesto

Per chattare a distanza, hai bisogno di un server dove far transitare i messaggi. Crealo gratis su Firebase in 2 minuti.

1. Vai su Firebase e crea un progetto.

2. Vai su Build > Firestore Database e crea un database in "Test Mode".

3. Vai su Build > Authentication e attiva l'accesso "Anonimo".

4. Vai nelle Impostazioni (Rotella) > Generali, aggiungi un'app Web () e copia il blocco di codice firebaseConfig.
